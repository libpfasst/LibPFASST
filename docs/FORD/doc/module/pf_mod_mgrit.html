public subroutine pf_MGRIT_v_cycle(pf, mg_ld, iteration)

Execute a MGRIT V-cycle (iteration) It is assumed that we have two levels and two nodes here When this is called the previous coarse integrator result should be stored in Q(1) and the MGRIT iteration in qend (both on coarse level).
